# 六自由度 V3.2 大姿态转向配对实验报告

日期：2026-09-02
结论：**V3.2 候选未通过冻结验收，当前正式版本仍为 V3.1。**

## 1. 实验目的与控制变量

V3.1 的原测试集中，150–300 m 时间确认后误报率为 11.53%。误报审计显示，正常姿态转向和航迹上下文切换是主要相关因素之一。本实验不修改 BiLSTM-attention 结构、时间确认规则、维护票据规则或 FTC，只增加 150–300 m 的正常/推力损失配对任务。

每个配对共享完全相同的动力学、推进器参数、传感器噪声、环境扰动、航迹和随机种子；配对间唯一的物理差异是是否注入指定推进器的推力损失。同一配对始终位于同一个 train/validation/test 划分中。

固定验收条件：

- 新增正常大转向测试的 temporal FAR 不超过 8%；
- operator FAR 不超过 0.3%；
- 正式维护票据误报为 0；
- 无输出故障票据召回保持 100%；
- 推力损失票据召回不低于 90%；
- 联合 F1 相比 V3.1 不下降超过 0.01；
- 检测延迟不应出现明显恶化。

### 4.4 分深度误报

这里的 150–300 m 包含原测试任务和新增配对任务，因此分母从原来的 425 个正常窗口增加到 1,636 个。

| 深度 | V3.1 temporal FAR | V3.2 temporal FAR | V3.2 operator FAR |
|---|---:|---:|---:|
| 0–50 m | 5.14% | 0% | 0% |
| 50–150 m | 6.98% | 2.93% | 0% |
| 150–300 m | 8.13% | 4.58% | 0% |
| 300–500 m | 5.43% | 3.88% | 0% |

原先 150–300 m 的 11.53% 来自较小的旧测试样本。新增独立任务后，V3.1 在该深度段的整体 temporal FAR 为 8.13%，在专门的正常大转向任务上为 7.49%。因此“水深本身造成 11.53% 误报”并不成立，旧结果包含明显的任务分割方差。

## 6. 验收结论

| 验收项 | 结果 | 是否通过 |
|---|---:|---:|
| 新增正常任务 temporal FAR ≤ 8% | 5.68% | 通过 |
| operator FAR ≤ 0.3% | 0% | 通过 |
| 锁定测试正式误票据为 0 | 0 | 通过 |
| validation 正式误票据为 0 | 1 个 | 未通过 |
| 无输出票据召回 100% | 100% | 通过 |
| 推力损失票据召回 ≥ 90% | 新增任务 75%；全部测试 80% | 未通过 |
| joint F1 不下降超过 0.01 | 提高 0.0315 | 通过 |
| 故障检测无明显退化 | 旧任务票据召回下降 11.11 个百分点 | 未通过 |

最终判断：数据扩充方向有效，已经证明正常大转向数据能降低误报并改善部分位置诊断；但当前从头训练的 V3.2 候选使模型对推力损失更保守，尤其没有解决 V2 弱故障，并导致旧任务票据召回下降。因此不能替换 V3.1，也不应修改现有 FTC。

下一轮若继续，应保持本次新测试不再用于调参，另建新的锁定测试；训练阶段改为“保留 V3.1 能力的增量训练或双批次 rehearsal”，并在 validation 模型选择中加入推力损失任务召回下限，而不是只按 joint F1 选 epoch。
