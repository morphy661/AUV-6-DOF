# 六自由度 V3.1 质量条件化修复结果

日期：2026-09-02
状态：候选版本，尚未冻结为最终 V3.1

## 修复目标

误报因果审计发现，V3 数据生成器把 50 kg 刚体质量随机化到约
41–59 kg，但诊断特征始终用固定标称广义质量计算期望加速度和推进器
运动损失证据。健康的高质量任务因此可能呈现类似推力损失的响应。

本次只修复该机制，不修改 FTC 规则：

- 刚体质量误差由 ±18% 收窄为 ±2%，即 49–51 kg；
- 保留惯量、附加质量、阻尼、传感器噪声及海流扰动随机化；
- 用明确传入的机载标定广义质量对期望加速度和运动损失证据进行条件化；
- 配置参数不从仿真日志或故障标签读取，避免标签泄漏；
- 原 V3 数据、模型和归档均未覆盖。

## 数据与训练协议

- 260 个任务，18,633 个长度为 100 的因果窗口；
- train / validation / test 为 182 / 39 / 39 个互不重叠任务；
- 0–300 m 占 90%，300–500 m 深水压力测试占 10%；
- 网络、损失函数、优化器和 30 epoch 上限与 V3 一致；
- 使用种子 42、43、44 独立训练；
- 模型选择只依据验证集联合 macro-F1，最终选择种子 42；
- 时间规则和维护票据规则只用验证集标定，测试集只做最终描述性评估。

## 因果修复是否命中目标

在 validation + test 的 78 个任务上，刚体质量与任务原始误报率的
Spearman 相关由修复前约 0.447 降为 -0.045（p=0.696）；与时间后误报率
的相关为 0.049（p=0.672）。当前小范围质量误差内已无可见质量依赖。

## 尚未解决的问题

- 底层模型仍会产生记录级误报，不能宣称误报已经消失；
- 独立测试中 150–300 m 的时间后误报率为 11.53%，高于其他深度段；
- 个别较弱推力损失窗口的精确推进器定位随训练种子波动，但正式票据层
  采用组别和 Top-2 候选，测试召回没有退化；
- 本结果仍是随机化仿真证据，不是实海试验或 300 m 硬件认证；
- 当前训练把每个虚拟车辆的广义质量视为已标定机载配置；实艇部署前必须
  用实际称重和水动力辨识结果替换 50 kg 标称参数；
- 学习模型仍只提供维护建议，未接管规则 FTC。

## 下一步建议

先保留该版本为 V3.1 候选，不再继续修改阈值。下一项应对 150–300 m
剩余误报做分层审计，重点区分姿态瞬态、控制饱和和水动力阻尼错配；在
该审计完成前不把 V3.1 标记为最终冻结版本。
