# 六自由度 V3.4 修正物理、重训练与外部盲测报告

日期：2026-09-03

## 1. 本阶段目的

本阶段不再通过提高报警阈值掩盖误报，而是先修正正常航行数据中不合理的动力学与偏航瞬态，再用新物理重新生成完整数据、重新训练模型并做一次锁定配置的外部盲测。

主要验收目标：

1. 正式维护工单不得由正常航行或故障前片段误触发；
2. 无输出故障必须保持高召回；
3. 推力损失若证据持续且充分则形成工单，短时或已恢复事件至少保留在 review log；
4. 0–300 m 为主要统计范围，300–500 m 仅作 10% 压力覆盖；
5. 模型选择和规则标定只使用训练/验证任务，外部盲测种子在锁定后才生成。

## 2. 有效代码修改

### 2.1 CG/CB 随机化

- 质量维持 50 kg 标称值、±2% 小范围误差，即 49–51 kg；
- CG 与 CB 的水平安装偏移改为相关采样；
- 两者共同水平偏移仍可达到 ±18 mm；
- CG–CB 每个水平轴的相对偏差限制为 ±2 mm；
- 保留竖直方向的重心/浮心分离以提供被动稳定性。

旧数据允许 CG 与 CB 在水平面独立采样，最大相对偏差可达到 36 mm，会把正常航行生成为大横滚、大俯仰甚至偏航振荡，从而制造物理含义含混的“正常”标签。

### 2.2 偏航控制

- 偏航姿态外环增益：1.8 → 1.2；
- 偏航角速度内环增益：18 → 30；
- 最大期望偏航角速度：0.65 → 0.50 rad/s。

修改目的为降低 50–60° 转向后的欠阻尼振荡，不改变六推进器布局和推力分配结构。

### 2.3 可追溯元数据

数据集生成器新增 `--dataset-version`，并在数据内记录：

- 动力学随机化配置；
- 控制器增益与限幅；
- CG/CB 相对偏差；
- 任务种子、深度带、速度、转向、故障时刻与剩余效率。

曾试验把推力损失正式确认时间扩展为 5、6.25、8 s 搜索，但最优结果仍为原来的 8 s。该无效复杂度已从正式代码撤回，只保留实验结果作为审计证据。

## 3. 修正后正常航行审计

相同 12 个审计任务、共 36 次计划转向的结果如下。

| 指标 | 修正后结果 |
|---|---:|
| 计划转向范围 | 33.57–59.95° |
| 指令结束时实际转向 | 30.32–54.33° |
| 指令后 5 s 实际转向 | 32.85–61.35° |
| 指令后 5 s 偏航误差，中位数 | 0.49° |
| 指令后 5 s 偏航误差，95 分位 | 1.79° |
| 指令后 5 s 偏航误差，最大值 | 2.60° |
| 全部任务横滚绝对最大值 | 3.65° |
| 全部任务俯仰绝对最大值 | 8.98° |
| 全部任务深度误差最大值 | 0.89 m |
| 推进器饱和率 | 0% |

这些结果说明原先的大姿态异常主要来自随机化与偏航控制设置，而不是六自由度模型必须出现的运动。当前姿态量级适合作为通用六推进器悬停型 AUV 的仿真基线，但不能据此声称已经复现某一台九工大 AUV 的实测数字孪生。

## 9. 阶段结论

V3.4 已解决本阶段最重要的问题：正常动力学不再制造明显不合理的大姿态响应，且外部盲测中正式误维护工单为 0。无输出故障保持 100% 工单召回；推力损失正式工单召回为 88.89%，但全部故障均保留在 review log，符合当前证据分级策略。

因此 V3.4 可以进入“候选冻结”，但暂不直接宣布最终冻结。下一项应是：使用修正物理生成独立的大转向配对任务，验证 33–60° 连续转向下的误报和推力损失留痕；随后再做一次 FTC 闭环安全回归并更新实时演示入口。若这两项通过，再把 V3.4 替换为统一演示和论文结果版本。
